# پروژه وب Flask — اخبار ارزهای دیجیتال

## مقدمه

این پروژه یک وب‌اپلیکیشن ساخته‌شده با فریمورک **Flask** (پایتون) است. کاربران می‌توانند در سایت ثبت‌نام کنند، وارد حساب خود شوند و در داشبورد شخصی، کلیدهای API خود را مدیریت کنند و آخرین اخبار مربوط به هر رمزارز را دریافت کنند.

هدف این پروژه بیشتر **آموزشی و نمونه‌کار** است؛ یعنی تمرین عملی مفاهیمی مثل احراز هویت با سشن (Session)، ذخیره‌سازی داده در فایل JSON و کار با APIهای خارجی.

## ویژگی‌ها

* **ثبت‌نام و ورود کاربران:** ایجاد حساب کاربری، ورود با مدیریت نشست (Session) و خروج از حساب.
* **داشبورد اختصاصی:** صفحه‌ی مخصوص کاربران واردشده با دسترسی سریع به ابزارها.
* **مدیریت کلیدهای API:** ثبت و ذخیره کلیدهای NewsAPI و CoinMarketCap از طریق صفحه‌ی اختصاصی.
* **دریافت اخبار رمزارزها:** endpoint جستجوی اخبار بر اساس نماد کوین (مثلاً `btc`) با خروجی JSON.
* **ذخیره‌سازی بدون دیتابیس:** اطلاعات کاربران و کلیدها در فایل‌های JSON نگهداری می‌شوند.
* **رابط کاربری سبک:** قالب‌های Jinja2 به‌همراه Tailwind CSS و استایل سفارشی.

## ساختار پروژه

```
project_flask_site/
├── app.py                 # کد اصلی برنامه و مسیرها

│   └── api_keys.json      # کلیدهای API

│   ├── signup.html        # ثبت‌نام
│   ├── dashboard.html     # داشبورد کاربر

    ├── css/styles.css

```

## پیش‌نیازها

* **Python 3.8+** — [دانلود پایتون](https://www.python.org/downloads/)
* **pip** — به‌صورت پیش‌فرض همراه پایتون نصب می‌شود.

> **نکته:** Tailwind CSS از CDN بارگذاری می‌شود، پس برای اجرای برنامه به Node.js و npm نیازی نیست. فایل `tailwind.config.js` فقط زمانی کاربرد دارد که بخواهید CSS تیلویند را به‌صورت محلی بازسازی کنید.

## نحوه نصب و اجرا

1. **کلون کردن مخزن:**

   ```bash
   git clone https://github.com/tahatehran/project_flask_site.git
   cd project_flask_site
   ```

2. **ساخت محیط مجازی (اختیاری اما توصیه‌شده):**

   ```bash
   python -m venv venv
   source venv/bin/activate      # لینوکس / مک
   venv\Scripts\activate         # ویندوز
   ```

3. **نصب وابستگی‌ها:**

   ```bash
   pip install -r requirements.txt
   ```

4. **اجرای برنامه:**

   ```bash
   python app.py
   ```

5. مرورگر را باز کنید و به آدرس زیر بروید:

   ```
   http://127.0.0.1:5000
   ```

## دریافت و تنظیم کلیدهای API

برای دریافت اخبار رمزارزها به کلید [NewsAPI](https://newsapi.org/) نیاز دارید (کلید [CoinMarketCap](https://coinmarketcap.com/api/) هم در صفحه مدیریت کلیدها پشتیبانی می‌شود):

1. در سایت NewsAPI ثبت‌نام کنید و کلید رایگان بگیرید.
2. پس از ورود به سایت، از داشبورد روی **Manage API Keys** کلیک کنید و کلیدها را وارد و ذخیره کنید.
3. کلیدها در فایل `data/api_keys.json` ذخیره می‌شوند.

## مسیرهای برنامه (Routes)

| مسیر | متد | توضیح |
|---|---|---|
| `/` | GET | صفحه اصلی |
| `/signup` | GET / POST | ثبت‌نام کاربر جدید |
| `/login` | GET / POST | ورود کاربر |
| `/logout` | GET | خروج از حساب |
| `/dashboard` | GET | داشبورد کاربر (نیازمند ورود) |
| `/api_keys` | GET / POST | مدیریت کلیدهای API (نیازمند ورود) |
| `/crypto_news/<symbol>` | GET | اخبار یک رمزارز به‌صورت JSON |

نمونه فراخوانی:

```
GET /crypto_news/btc
```

نمونه خروجی:

```json
[
  {
    "title": "...",
    "description": "...",
    "url": "...",
    "publishedAt": "..."
  }
]
```

## نکته امنیتی

این پروژه یک نمونه‌ی آموزشی است: رمزهای عبور به‌صورت متن ساده در `data/users.json` ذخیره می‌شوند و `secret_key` مقدار ثابتی در کد دارد. برای استفاده در محیط واقعی حتماً رمزها را هش کنید و `secret_key` را از متغیر محیطی بخوانید.
